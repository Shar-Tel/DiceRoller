Programa para Arduino que permite simular el lanzamiento de distintos tipos de dados. Está preparado para su uso con una pantalla con 4 digitos de 7 segmentos. También está preparado para su uso con 3 botones: uno elige el número de caras del dado a lanzar (por defecto es de 100), otro lanza el dado y el último tira iniciativa según una variante del juego de rol Rolemaster (lanza 2d10 y suma el resultado, si alguno de los dados saca 10 lo vuelve a lanzar y también suma esa tirada al resultado) ![IMG_20250723_113506](https://github.com/user-attachments/assets/524c102b-7567-4946-8701-4a8f6ecc98ed)
